Changelog

Changes to this map/explorer tool itself — not to the game. See the About box for the game version this map is current with.

2026-10-17

  • Added: a language picker in the toolbar. The map is now available in Deutsch, Español, Français, Italiano, Português, Русский, 한국어 and 简体中文, using the game's own translations for the dialogue. Each language has its own layout, so longer text still fits its box.
  • Note: the game's Korean and Chinese translations currently stop around Day 26, so later choices show in English in those languages. The guided tour and this changelog stay in English.
  • Added: search also finds the English text while another language is selected.
  • Changed: the legend's Tracker Mode entries (already unlocked, disabled due to route chosen) only show while you're in Tracker Mode.

2026-10-12

  • Updated: map data refreshed for game version v0.4.0.2.
  • Added: new social-post pictures that v0.4.0.2 adds, mostly Valerie-focused — Valerie Pictures 19–26, plus a few new Mabel/Misc campus-life posts, all now shown on the map with their trigger choice/day.
  • Added: search for "new" to list everything added in this update (the nodes marked with a gold ★).
  • Added: a flag tracker in Tracker Mode. With a save loaded, the new "Flags" button lists every story flag that save has set — route flags first — with the day each is set, and clicking one jumps to the choice that set it.
  • Fixed: route boxes no longer overlap each other; a sub-route (e.g. Day 27's Romance/Lust Kiss inside Day 26's Love/Lust) now sits fully inside its parent box.
  • Fixed: condition labels and route-box titles no longer cover nodes or each other. Labels slide along their line to a clear spot, and a route title that has no room when zoomed far out is hidden until you zoom in.
  • Fixed: branches that can never actually happen are no longer drawn — e.g. Day 6's if not ClubOutfitA Flag and not ClubOutfitB Flag (every outfit choice sets one of them), or a second "neither" ending in Day 28 Evening. Pictures that depend on an earlier choice in the same scene now hang straight off that choice.
  • Fixed: several wrong or missing condition labels, such as an if X on a line that's actually reached either way.
  • Changed: route and day headers only list the flags that set them apart (e.g. the Romance/True Love route no longer shows NTS).
  • Changed: where several paths meet right before a choice or condition, they now join at a small dot first instead of each drawing its own crossing line into every branch.
  • Changed: dotted lines that run side by side are drawn in different colors so each can be followed.
  • Changed: the blank "[Continues here without …]" boxes are gone; their condition is now on the line itself. Where a route simply stops, the box reads "End of route as of current version!".

2026-08-27

  • Fixed: nested branches (e.g. Trust/Desire splits) no longer show a bloated combined condition like if Trust < 50 and Desire > 0 / if Trust < 50 and else on every edge — only the condition that actually determines each outcome shows.
  • Fixed: the same picture reached from two mutually-exclusive branches (e.g. an NTR/NTS split both leading to the same image) now merges into one node instead of drawing duplicates.
  • Added: dead branches — re-checking a stat that an earlier branch already locked in — are now pruned instead of drawn as if still reachable.
  • Changed: when several mutually-exclusive branches each set a different flag and reconverge (e.g. Day 17's NTR/NTS × Lust/Love split), the flag note now shows exactly which condition sets each one instead of listing all of them with no attribution.
  • Changed: else now shows the actual negated condition (e.g. if not Mabel Trust < 50) instead of the bare word "else".
  • Changed: a condition now only appears once, on the edge that actually enters its gated branch — it no longer repeats on every edge further down inside that same branch.

2026-08-23

  • Fixed: several missing route endings, including Day 27 Night's Erika/Nina scenes and two Phone-Upgrades-dependent endings in Mabel's Day 28 finale.
  • Fixed: several missing route-branch boxes — Day 27 Night's Erika/Nina split, Day 27's Romance/Lust-Kiss split, and Day 26's Jessica-vs-Valerie choice.
  • Fixed: some content rendering out of order in the tree, and stray nodes/arrows appearing far from where they belong.
  • Fixed: the minimap was pinned to the top-left instead of centered.
  • Fixed: Hailey was missing from the legend.
  • Changed: confusing condition markers/labels (e.g. [if not JasonRt Flag], if X or else or Y) now read as plain sentences.
  • Added: the guided tour now covers the Changelog button.
  • Fixed: Day 26's Jessica and Valerie route boxes were both colored Mabel's pink instead of their own colors.
